Server

This page documents how to start and stop a server: serve and serve!, the Server they create, and the functions that act on it. For every keyword in one table, see Configuration; for when to use which, the handlers guide.

NameUse
servestart a server and block; the last line of a server program
serve!start a server and return it; for tests, the REPL, several servers
Serverthe running server
close(server)stop it, optionally with a grace period
wait(server)block until it has stopped
isopen(server)whether it still accepts connections
port(server)the port it listens on
Facil.connections(server)its open connections
Facil — Module
Facil

An HTTP/1.1 server for Julia built on facil.io.

serve and serve! run a handler: a function that takes an HttpTypes Request and returns a Response. The same handler can answer with a streamed response (stream), an event stream (sse), a file (sendfile) or a WebSocket (websocket). Facil also has pub/sub (publish), timers (every) and HTTPS (TLSConfig).

Facil re-exports every name of HttpTypes, so using Facil is all a server needs.

Examples

julia> using Facil

julia> import Downloads

julia> server = serve!(0) do req
           Response(StatusCodes.OK, "hello")
       end;

julia> String(take!(Downloads.download("http://127.0.0.1:$(port(server))/", IOBuffer())))
"hello"

julia> close(server)

Starting a server

Facil.serve! — Function
serve!(handler, host = "127.0.0.1", port = 8080; kw...) -> Server
serve!(handler, port::Integer; kw...) -> Server

Start an HTTP server and return it without blocking.

handler is called once per request with a Request{String} and returns the response. It is the first argument, so do syntax works.

Arguments

  • handler: any callable handler(req) -> result. result is one of
    • a Response whose body is a String, a Vector{UInt8} or nothing;
    • a String, sent as 200 with content-type: text/plain; charset=utf-8;
    • what stream, sse, sendfile or websocket returns.
  • host::AbstractString = "127.0.0.1": the address to bind. "0.0.0.0" listens on every IPv4 interface, "::1" and "::" are the IPv6 forms, and a host name such as "localhost" is resolved.
  • port::Integer = 8080: 0 to 65535. 0 picks a free port; read it back with port(server).

Keywords

Handlers and threads (see the handlers guide):

  • inline::Bool = false: false runs the handler on a task of Facil's worker pool, so it may block (wait for I/O, take a lock, call Facil.sleep). true runs it on the reactor thread, inside the event loop: less work per request, but a handler that blocks stalls every connection on that thread. When Julia has one thread (julia -t 1) handlers always run inline.
  • reactors::Integer = 1: reactor threads. Process-wide: the first server fixes the number and a later server asking for another throws.

Limits (see Limits):

  • max_header_size::Integer = 32768: bytes of request head; more gets a 431. At least 1024.
  • max_body_size::Integer = 50 MiB: bytes of request body; more gets a 413.
  • body_in_memory::Integer = 16 MiB: largest body Buffer keeps in memory; more gets a 413.
  • timeout::Integer = 40: seconds an idle connection is kept open, 1 to 255.
  • header_timeout::Integer = 30: seconds a client has to send a complete request head. A client still trickling its head after that gets a 408 and is disconnected; one that has gone silent is closed by timeout instead. 0 turns the check off, at most 3600. Process-wide: the last server started sets it.
  • max_pending_output::Integer = 16 MiB: a client with more unsent response bytes than this that stops reading for about 3 seconds is disconnected; 0 turns the check off.

Request bodies (see the request bodies guide):

  • before_body = head -> Buffer(): called with a RequestHead when a request has a body, before the body is read. Returns Buffer(), Stream(), Spool() or Reject(status). It runs on the reactor thread and must not block.

Responses:

  • compress = false: true or a CompressOptions compresses handler results (zstd, brotli or gzip, chosen from Accept-Encoding), on the thread that ran the handler.
  • public_folder::Union{Nothing,AbstractString} = nothing: a directory whose files are served for GET, HEAD and OPTIONS before the handler is called; requests that match no file reach the handler. See sendfile for the headers. A path with an encoded NUL (%00) gets a 400.
  • dotfiles::Symbol = :serve: :deny does not serve a file whose path has a part that starts with a dot (.env, .git/config); such a request reaches the handler as if the file did not exist. Needs public_folder.
  • symlinks::Symbol = :follow: :inside does not serve a file that resolves, through symbolic links, to a place outside public_folder; such a request reaches the handler. Needs public_folder.

HTTPS:

  • tls = nothing: a TLSConfig makes this an HTTPS server. Needs reactors = 1.

Operation:

  • shutdown_grace::Real = 10: seconds serve gives requests in progress when the process gets SIGTERM. See serve for what differs on Julia 1.10 and 1.11.
  • verbose::Bool = false: write one line to stderr at start-up (address, threads, limits), one for each request that before_body rejects or that is over body_in_memory, and one when the server starts to drain.
  • gc_headroom::Integer = 0: bytes of heap headroom; see Facil.gc_headroom!.

Returns

The running Server. The listener is bound when serve! returns, so a client may connect at once.

Throws

  • ArgumentError: an unknown keyword (the message names the closest valid one), a keyword out of range, port outside 0:65535, a NUL in host, public_folder that is not a directory, dotfiles or symlinks with another value or without public_folder, tls that is not a TLSConfig, tls with reactors > 1, or reactors different from the reactor already running.
  • SystemError: the address could not be bound, for example Address already in use when another process holds the port.

What Facil does around the handler

  • A handler that throws, or returns anything not listed above, gives a 500 with the body Internal Server Error. The error and its stack trace are written to stderr, at most once per error type and call site every 10 seconds.
  • A request whose target or header names HttpTypes rejects gets a 400 without reaching the handler. So does a request without a Host header, and one whose request line has a space inside the target.
  • The status line carries the status you return, with canonical_reason(status) as its phrase, or Unknown when it has none. A 1xx, 204 or 304 response is sent without its body and without content-length.
  • content-length (or chunked framing) is always set by Facil; a content-length or transfer-encoding you set is ignored. A non-empty body without content-type gets text/plain; charset=utf-8 (a String) or application/octet-stream (bytes). facil.io adds date, last-modified and connection when you did not set them.
  • A response body is sent without a copy. Do not change a Vector{UInt8} after returning it.
  • A HEAD request gets the head your handler produced, without the body.
  • A client that disconnects while its handler runs is not noticed: the handler finishes and its result is discarded.

Examples

julia> using Facil

julia> import Downloads

julia> server = serve!(0) do req
           if path(uri(req)) == "/"
               Response(StatusCodes.OK, "home")
           else
               Response(StatusCodes.NOT_FOUND, "no such page")
           end
       end;

julia> base = "http://127.0.0.1:$(port(server))";

julia> String(take!(Downloads.download(base * "/", IOBuffer())))
"home"

julia> Downloads.request(base * "/nope").status
404

julia> close(server)

serve! with options, as a server meant for short non-blocking handlers:

julia> using Facil

julia> server = serve!(req -> "pong", "127.0.0.1", 0; inline = true, max_body_size = 1024, timeout = 10);

julia> isopen(server)
true

julia> close(server)

See also serve, Server, and the configuration reference.

Facil.serve — Function
serve(handler, host = "127.0.0.1", port = 8080; kw...)
serve(handler, port::Integer; kw...)

Start an HTTP server and block until it is closed.

Takes the arguments and keywords of serve! and throws what it throws. Use serve as the last line of a server program and serve! when the program has more to do (tests, several servers, a REPL session).

Returns

nothing, once the server has stopped.

Stopping

  • At the REPL, Ctrl-C closes the server and serve returns.
  • SIGTERM (kill <pid>, systemctl stop, docker stop) drains: a task calls close(server; grace = shutdown_grace) for every open server of the process (default 10 seconds), and the process exits with status 143. Julia prints its own signal 15: Terminated report to stderr first; that is not an error. On Julia 1.12 and later every handler can finish during the drain: the first serve moves Julia's event loop to a thread of its own (Base.Experimental.make_io_thread), because the thread that normally runs it is the one a signal interrupts. Julia 1.10 and 1.11 cannot do that: there a handler waiting on a socket, a file, a process or Base.sleep never returns and its client is cut off when the grace period ends. To drain those, call close(server; grace) yourself before the process is stopped; see the shutdown guide.
  • In a script (julia server.jl), Ctrl-C ends the process the way Julia ends any script on SIGINT: Julia prints its signal 2: Interrupt report, then the same drain runs and the process exits.
  • Under julia -e, or after Base.exit_on_sigint(false), Ctrl-C does not stop serve. Send SIGTERM.
  • Another task may call close(server); serve does not hand you the server, so use serve! and wait for that.

Examples

A complete program. Save it as hello.jl, run julia -t 4 hello.jl, then open http://127.0.0.1:8080/:

using Facil

serve("127.0.0.1", 8080) do req
    Response(StatusCodes.OK, "hello")
end

This is docs/examples/hello.jl, which the documentation build starts and requests. See the shutdown guide for signals.

The Server object

Facil.Server — Type
Server

A listening HTTP server, returned by serve!.

A Server is not constructed directly. It supports:

CallResult
close(server; grace = 0)stop listening and close its connections
wait(server)block until it has stopped
isopen(server)true until close is called
port(server)the port it listens on
Facil.connections(server)open connections
reload!(server; cert, key)replace an HTTPS server's certificate

show prints the address and state, for example Facil.Server("127.0.0.1", 8080, open). The states are open, closing (after close, while connections finish) and closed.

Every server in a process shares one reactor. A process may run several servers, each with its own handler, limits and inline setting.

Examples

julia> using Facil

julia> server = serve!(req -> "ok", 0);

julia> isopen(server)
true

julia> close(server); wait(server)

julia> isopen(server)
false

Base.close — Method
close(server::Server; grace = 0)

Stop server. Returns nothing at once; wait(server) blocks until it has stopped.

Keywords

  • grace::Real = 0: seconds that requests in progress get to finish.
    • 0: stop listening and close every connection as soon as the output already queued for it is sent. A handler that is still running finishes, but its response is discarded.
    • > 0: stop listening, let each request in progress reply (the reply closes its connection), close idle connections within about 2 seconds and WebSockets at once, and close whatever is left after grace seconds. Other servers in the process are not affected.

Notes

  • Calling close again, or on a closed server, does nothing.
  • The reactor keeps running for the life of the process; closing a server closes only its listener and its connections.
  • Each WebSocket of the server gets its on_shutdown callback and a 1001 close frame, then on_close; with grace, as soon as the drain starts. Streamed responses and event streams are cut; their isopen(io) turns false. With grace, they keep the server open until grace runs out.
  • serve calls close for you on Ctrl-C at the REPL, and close(server; grace = shutdown_grace) on SIGTERM.

Examples

julia> using Facil

julia> server = serve!(req -> "ok", 0);

julia> close(server; grace = 5)

julia> wait(server)

julia> occursin("closed", string(server))
true

See the shutdown guide.

Base.wait — Method
wait(server::Server)

Block the calling task until server has stopped: it no longer listens and every one of its connections is closed.

Returns nothing. Returns at once for a server that is already closed. serve is serve! followed by wait. Pair it with close from another task, a timer or a signal; on its own it blocks for as long as the server runs.

source
Base.isopen — Method
isopen(server::Server) -> Bool

Whether server is still accepting connections.

Returns true from serve! until close is called on it (or the reactor stops), and false afterwards, including while its last connections are still finishing. Use wait to learn when those are gone.

Facil.connections — Function
Facil.connections(server::Server) -> Int

The number of connections server holds open right now: idle keep-alive connections, requests in progress, streams, and WebSockets upgraded on it. 0 for a closed server. Useful for a metrics endpoint or to watch a drain.

Facil.drain_server! — Function
Facil.drain_server!(server::Server, grace::Real)

What close(server; grace) does for grace > 0: stop accepting, let each request in progress reply (the reply closes its connection), close idle connections within about 2 seconds, and after grace seconds close whatever is left. Returns at once; wait(server) blocks until the server is closed. Prefer close(server; grace).
