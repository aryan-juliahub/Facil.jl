Tuning and diagnostics

This page documents the functions that report what a running process is doing and the one garbage-collector knob Facil has. All are process-wide and cheap enough to call from a metrics endpoint. The performance guide says when each one matters.

CounterCounts
Facil.connections(server)open connections of one server
Facil.paused_requests()requests whose task handler has not finished
Facil.pending_bodies()request bodies being received
Facil.pinned_bodies()response bodies not yet fully written
Facil.live_streams()open streamed responses and event streams
Facil.open_websockets()open WebSocket connections
Facil.gc_headroom! — Function
Facil.gc_headroom!(bytes::Integer) -> Int

Keep bytes of heap headroom so Julia's garbage collector runs less often.

Facil holds a block of bytes that is allocated but never written. The collector sizes its heap from what is live, so it behaves as if that much more were in use: fewer collections when handlers allocate large temporaries. The block costs address space, not resident memory.

Arguments

  • bytes: the headroom wanted, >= 0.

Returns

The headroom now held, in bytes. Headroom only grows: a smaller bytes than before changes nothing, and gc_headroom!(0) just reports the current value.

Throws

  • ArgumentError if bytes is negative.

Notes

Process-wide. serve!(...; gc_headroom = n) calls this. It does not help every load: measure before keeping it (see the performance guide).

Examples

julia> using Facil

julia> Facil.gc_headroom!(0) >= 0
true

Facil.paused_requests — Function
Facil.paused_requests() -> Int

The number of requests whose task handler is running (or waiting for a worker) right now, across every server. Inline handlers are never counted. A value that stays high means handlers are slower than requests arrive.

source
Facil.pinned_bodies — Function
Facil.pinned_bodies() -> Int

The number of response bodies Facil is holding for facil.io because they are being sent without a copy. It returns to 0 when every response has been written to its socket; a value that keeps growing means clients are not reading.

source
Facil.live_streams — Function
Facil.live_streams() -> Int

The number of streamed responses (stream) and event streams (sse) that are still open, across every server.

source

A metrics endpoint built from the counters:

using Facil

const SERVER = Ref{Server}()

function metrics()
    """
    facil_connections $(Facil.connections(SERVER[]))
    facil_paused_requests $(Facil.paused_requests())
    facil_pending_bodies $(Facil.pending_bodies())
    facil_pinned_bodies $(Facil.pinned_bodies())
    facil_live_streams $(Facil.live_streams())
    facil_open_websockets $(Facil.open_websockets())
    """
end

function app(req)
    path(uri(req)) == "/metrics" && return Response(StatusCodes.OK, metrics())
    Response(StatusCodes.OK, "hello")
end

SERVER[] = serve!(app, "127.0.0.1", 8080)
wait(SERVER[])
