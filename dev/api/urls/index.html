Queries, forms and cookies

Helpers that decode the request target and form bodies, and read and write cookies. The guides Query strings, paths and forms and Cookies show them in complete programs.

Query strings and paths

Facil.query_param — Function
query_param(req::Request, name; default = nothing)

The decoded value of the first query parameter called name, or default when there is none. Names compare exactly, after decoding. Only the names are decoded until the match is found.

Examples

julia> req = Request(; uri = "/search?q=julia+web&page=2&q=other");

julia> query_param(req, "q"), query_param(req, "missing"), query_param(req, "n"; default = "1")
("julia web", nothing, "1")
source
Facil.query_params — Function
query_params(req::Request) -> Vector{Pair{String,String}}

The query of the request target as decoded name => value pairs, in order, repeated names included: parse_query of query(uri(req)). Empty when the target has no query.

Examples

julia> req = Request(; uri = "/search?q=julia+web&tag=a&tag=b");

julia> query_params(req)
3-element Vector{Pair{String, String}}:
   "q" => "julia web"
 "tag" => "a"
 "tag" => "b"

julia> [v for (k, v) in query_params(req) if k == "tag"]
2-element Vector{String}:
 "a"
 "b"
source
Facil.decoded_path — Function
decoded_path(req::Request) -> Union{String,Nothing}

The path of the request target with %XX escapes decoded (/caf%C3%A9 gives "/café"). + stays +: it is a space only in queries and forms.

Returns nothing, so you can answer 400, when decoding would be ambiguous or unsafe: a malformed escape (%zz, %4), an escaped / (%2F), an escaped NUL (%00), or bytes that are not valid UTF-8. The result is not normalised: %2E%2E decodes to ... To accept %2F inside a segment, split path(uri(req)) on / first and percent_decode each segment.

Examples

julia> decoded_path(Request(; uri = "/caf%C3%A9/a+b"))
"/café/a+b"

julia> decoded_path(Request(; uri = "/files/a%2Fb")) === nothing
true
source
Facil.parse_query — Function
parse_query(s) -> Vector{Pair{String,String}}

Split a query string or application/x-www-form-urlencoded text into name => value pairs, in order, as URLSearchParams does: pairs are separated by &, the first = separates name and value (a piece without = has the value ""), + is a space, and both sides are percent_decoded. Empty pieces are skipped, a leading ? is ignored, and a repeated name gives one pair per occurrence.

Examples

julia> parse_query("tag=a&tag=b&q=caf%C3%A9+au+lait&flag")
4-element Vector{Pair{String, String}}:
  "tag" => "a"
  "tag" => "b"
    "q" => "café au lait"
 "flag" => ""
source
Facil.parse_form — Function
parse_form(body) -> Vector{Pair{String,String}}
parse_form(req::Request) -> Vector{Pair{String,String}}

Parse an application/x-www-form-urlencoded body (a string or bytes) with the same rules as parse_query. Given a request, parses body(req); check its content-type first if your handler also accepts other bodies.

Examples

julia> req = Request(; method = "POST", uri = "/login", body = "user=ada&note=hi+there%21");

julia> parse_form(req)
2-element Vector{Pair{String, String}}:
 "user" => "ada"
 "note" => "hi there!"
source
Facil.percent_decode — Function
percent_decode(s; plus = false) -> String

Decode %XX escapes in s. With plus = true, + also becomes a space, as in a query string or form body.

Decoding is lenient, like the WHATWG URL standard: a % that is not followed by two hex digits is kept as it is, and bytes that are not valid UTF-8 after decoding become '\ufffd'. It never throws on client input.

Examples

julia> percent_decode("caf%C3%A9%20au%20lait")
"café au lait"

julia> percent_decode("a+b%2Bc"; plus = true)
"a b+c"

julia> percent_decode("100%")
"100%"
source
Facil.percent_encode — Function
percent_encode(s) -> String

Escape every byte of s except the RFC 3986 unreserved characters (A-Z a-z 0-9 - . _ ~) as %XX. The result is safe in a path segment, a query name or value, a form body and a cookie value; percent_decode reverses it.

Examples

julia> percent_encode("café & co/2")
"caf%C3%A9%20%26%20co%2F2"

Cookies

Facil.cookies — Function
cookies(req::Request; unescape = false) -> Dict{String,String}

The cookies the client sent, from every cookie header, as name => value.

Parsing is lenient, as RFC 6265 §5.4 asks of servers: each header is split on ;, spaces and tabs around each piece are trimmed, the first = separates name and value, and a value wrapped in double quotes loses them. Pieces with no = or an empty name are skipped. When a name repeats, the first value wins (browsers send the most specific cookie first).

Values are returned as sent. With unescape = true each value is percent_decoded, which reverses set_cookie!(...; escape = true).

Examples

julia> req = Request(; headers = ["cookie" => "sid=abc123; theme=\"dark\"", "cookie" => "sid=old; lang=en"]);

julia> c = cookies(req);

julia> c["sid"], c["theme"], c["lang"]
("abc123", "dark", "en")
source
Facil.set_cookie! — Function
set_cookie!(res::Response, name, value; path = nothing, domain = nothing,
            max_age = nothing, expires = nothing, secure = false,
            http_only = false, same_site = nothing, partitioned = false,
            escape = false) -> res

Append one set-cookie header to res; call it once per cookie.

  • name must be an HTTP token (letters, digits and $!#$%&'*+-.^_`|~$).
  • value must consist of cookie octets: visible ASCII except space, ", ,, ; and \. Pass escape = true to percent_encode it first (read it back with cookies(req; unescape = true)), or encode it yourself.
  • max_age is in seconds (an Integer or a Dates.Period); expires is a DateTime in UTC, sent as an IMF-fixdate.
  • same_site is :strict, :lax or :none. :none and partitioned = true require secure = true, as browsers do.
  • A name starting with __Secure- requires secure = true; one starting with __Host- also requires path = "/" and no domain.

Throws an ArgumentError for anything a browser would reject or that would break the header.

Examples

julia> res = Response(StatusCodes.OK, "ok");

julia> set_cookie!(res, "sid", "abc123"; path = "/", http_only = true, secure = true, same_site = :lax);

julia> set_cookie!(res, "theme", "dark"; max_age = 3600);

julia> String.(get_all(headers(res), "set-cookie"))
2-element Vector{String}:
 "sid=abc123; Path=/; Secure; HttpOnly; SameSite=Lax"
 "theme=dark; Max-Age=3600"
source
Facil.delete_cookie! — Function
delete_cookie!(res::Response, name; path = nothing, domain = nothing, kw...) -> res

Tell the client to drop the cookie name: a set-cookie with an empty value, Max-Age=0 and an Expires in 1970. path and domain must match the ones the cookie was set with, or the browser keeps it. Other keywords go to set_cookie! (a __Host- cookie needs secure = true, path = "/").

Examples

julia> res = delete_cookie!(Response(StatusCodes.OK, "bye"), "sid"; path = "/");

julia> String(headers(res)["set-cookie"])
"sid=; Path=/; Max-Age=0; Expires=Thu, 01 Jan 1970 00:00:00 GMT"
