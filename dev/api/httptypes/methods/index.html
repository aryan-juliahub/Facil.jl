Methods

This page documents HttpMethod, the type of a request's method, and the Methods constants. Use it when you branch on the method of a request or need to know which methods count as safe or idempotent.

Using methods

method(req) returns an HttpMethod. Compare it with a constant or with a string:

julia> using HttpTypes
julia> req = Request(; method = "POST", uri = "/users");
julia> method(req) == Methods.POSTtrue
julia> method(req) == "POST"true

The ten standard methods are constants. Any other valid token is an extension method and works the same way:

julia> purge = HttpMethod("PURGE")HttpMethod("PURGE")
julia> purge == "PURGE", is_safe(purge)(true, false)

Methods are case-sensitive, as HTTP requires. "get" is a valid token, but it is not GET:

julia> HttpMethod("get") == Methods.GETfalse

Reference

HttpTypes.HttpMethod — Type
HttpMethod(src)
HttpMethod(ptr::Ptr{UInt8}, len::Integer)
HttpMethod()
tryparse(HttpMethod, src)
tryparse(HttpMethod, ptr, len)
parse(HttpMethod, src)

A request method: GET, POST, or any other RFC 9110 token.

The ten standard methods are constants in Methods (Methods.GET, ...), and parsing one of their names returns that constant. Any other valid token becomes an extension method that keeps its text.

Arguments

  • src: an AbstractString or AbstractVector{UInt8} holding the method name, or an HttpMethod (returned as is).
  • ptr, len: a pointer to len bytes holding the name; the bytes are copied only for an extension method.

Returns

An HttpMethod. HttpMethod() is Methods.GET. The tryparse forms return nothing instead of throwing.

Throws

  • InvalidMethod if src is empty or contains a byte outside the token characters (letters, digits and the punctuation RFC 9110 allows in a token; no spaces, control bytes or non-ASCII bytes).

Notes

  • Methods are case-sensitive: HttpMethod("get") is an extension method, not Methods.GET.
  • m == "GET" compares with a string. Two extension methods are equal when their text is equal. Methods order (isless) and hash by their text.
  • string(m), String(m), print and as_str give the token; show prints Methods.GET or HttpMethod("PURGE").
  • convert(HttpMethod, src) accepts strings and bytes, so a field or argument typed HttpMethod can be assigned a string.

Examples

julia> HttpMethod("POST")
Methods.POST

julia> HttpMethod("POST") === Methods.POST
true

julia> m = HttpMethod("PURGE")
HttpMethod("PURGE")

julia> m == "PURGE", string(m)
(true, "PURGE")

julia> HttpMethod("get") == Methods.GET
false

julia> tryparse(HttpMethod, "not a method") === nothing
true

See also is_safe, is_idempotent.

HttpTypes.Methods — Module
Methods

The standard request methods as HttpMethod constants:

Methods.OPTIONS, Methods.GET, Methods.POST, Methods.PUT, Methods.DELETE, Methods.HEAD, Methods.TRACE, Methods.CONNECT, Methods.PATCH, Methods.QUERY.

The constants are not exported one by one; write Methods.GET.

Examples

julia> Methods.DELETE
Methods.DELETE

julia> Methods.GET == "GET"
true

HttpTypes.is_safe — Function
is_safe(m::HttpMethod) -> Bool

Whether the method is safe, that is read-only (RFC 9110 §9.2.1): GET, HEAD, OPTIONS, TRACE and QUERY. Extension methods are never safe.

Examples

julia> is_safe(Methods.GET), is_safe(Methods.POST), is_safe(HttpMethod("PURGE"))
(true, false, false)
source
HttpTypes.is_idempotent — Function
is_idempotent(m::HttpMethod) -> Bool

Whether repeating the request has the same effect as sending it once (RFC 9110 §9.2.2): the safe methods (see is_safe) plus PUT and DELETE. Extension methods are never idempotent.

Examples

julia> is_idempotent(Methods.PUT), is_idempotent(Methods.POST)
(true, false)
