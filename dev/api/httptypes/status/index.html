Status codes

This page documents StatusCode, the type of a response's status, and lists every StatusCodes constant. Use it to find the constant for a code, to build a code that has no constant, or to classify a code.

Using status codes

Pass a constant to Response:

julia> using HttpTypes
julia> res = Response(StatusCodes.NOT_FOUND, "no such user");
julia> status(res)StatusCodes.NOT_FOUND
julia> status(res) == 404true
julia> string(status(res))"404 Not Found"

An integer works wherever a status is expected next to a body, and for field assignment. A code without a constant is built with StatusCode(n):

julia> status(Response(404, "no such user"))StatusCodes.NOT_FOUND
julia> res.status = 410;
julia> status(res)StatusCodes.GONE
julia> StatusCode(299)StatusCode(299)
Note

Response(404) with a single integer argument throws an ArgumentError, because it could mean "status 404" or "body 404". Write Response(StatusCodes.NOT_FOUND) for an empty response.

Classify a code with the is_* functions:

julia> is_success(StatusCodes.CREATED), is_client_error(StatusCodes.NOT_FOUND), is_server_error(StatusCodes.BAD_GATEWAY)(true, true, true)

HttpTypes.StatusCode — Type
StatusCode(code::Integer)
StatusCode(src)
StatusCode(ptr::Ptr{UInt8}, len::Integer)
StatusCode()
tryparse(StatusCode, src)
parse(StatusCode, src)

An HTTP status code in 100:999.

Registered codes are constants in StatusCodes (StatusCodes.OK, ...). Codes that are not registered are valid too, as long as they are in range.

Arguments

  • code::Integer: the numeric code.
  • src: an AbstractString or AbstractVector{UInt8} of exactly three ASCII digits, or a StatusCode (returned as is).
  • ptr, len: a pointer to len bytes holding the digits.

Returns

A StatusCode. StatusCode() is StatusCodes.OK. tryparse accepts the same sources (including an integer) and returns nothing instead of throwing.

Throws

  • InvalidStatusCode if the code is outside 100:999 or the text is not three digits.

Notes

  • UInt16(s) and Int(s) give the number; s == 404 compares with an integer. Codes order (isless) by number.
  • as_str gives the digits ("404"). string(s) and print give the digits and the reason phrase ("404 Not Found"), or "299 <unknown status code>" for an unregistered code.
  • show prints StatusCodes.NOT_FOUND, or StatusCode(299) for an unregistered code.
  • convert(StatusCode, x) accepts integers, strings and bytes, so response.status = 404 works.

Examples

julia> StatusCode(404)
StatusCodes.NOT_FOUND

julia> StatusCode("201") === StatusCodes.CREATED
true

julia> s = StatusCode(299)
StatusCode(299)

julia> Int(s), string(s), canonical_reason(s)
(299, "299 <unknown status code>", nothing)

julia> StatusCodes.OK == 200, string(StatusCodes.OK)
(true, "200 OK")

See also canonical_reason, is_success, is_client_error, is_server_error.

HttpTypes.StatusCodes — Module
StatusCodes

The registered status codes as StatusCode constants, named as in the http crate: StatusCodes.OK (200), StatusCodes.CREATED (201), StatusCodes.NO_CONTENT (204), StatusCodes.MOVED_PERMANENTLY (301), StatusCodes.FOUND (302), StatusCodes.NOT_MODIFIED (304), StatusCodes.BAD_REQUEST (400), StatusCodes.UNAUTHORIZED (401), StatusCodes.FORBIDDEN (403), StatusCodes.NOT_FOUND (404), StatusCodes.METHOD_NOT_ALLOWED (405), StatusCodes.PAYLOAD_TOO_LARGE (413), StatusCodes.UNPROCESSABLE_ENTITY (422), StatusCodes.TOO_MANY_REQUESTS (429), StatusCodes.INTERNAL_SERVER_ERROR (500), StatusCodes.SERVICE_UNAVAILABLE (503) and the rest of the registry: 62 constants in all.

The constants are not exported one by one; write StatusCodes.OK. A code without a constant is built with StatusCode(n).

Examples

julia> StatusCodes.IM_A_TEAPOT
StatusCodes.IM_A_TEAPOT

julia> Int(StatusCodes.IM_A_TEAPOT), canonical_reason(StatusCodes.IM_A_TEAPOT)
(418, "I'm a teapot")
