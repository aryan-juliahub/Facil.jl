Versions

This page documents Version, the HTTP protocol version carried by every Request and Response.

Using versions

version(req) returns one of five constants. They are ordered oldest first, so you can compare them:

julia> using HttpTypes
julia> req = Request(Methods.GET, "/");
julia> version(req)Versions.HTTP_11
julia> version(req) >= Versions.HTTP_11true
julia> string(version(req))"HTTP/1.1"
ConstantText
Versions.HTTP_09HTTP/0.9
Versions.HTTP_10HTTP/1.0
Versions.HTTP_11HTTP/1.1
Versions.HTTP_2HTTP/2.0
Versions.HTTP_3HTTP/3.0

The type only names a version. Which versions a server speaks is up to the server: Facil speaks HTTP/1.1 and HTTP/1.0.

Reference

HttpTypes.Version — Type
Version
Version()

The HTTP protocol version of a request or response.

There are exactly five values, the constants in Versions: Versions.HTTP_09, Versions.HTTP_10, Versions.HTTP_11, Versions.HTTP_2 and Versions.HTTP_3. A Version cannot be parsed from text or built from a number.

Returns

Version() is Versions.HTTP_11, the default of Request and Response.

Notes

  • Versions are ordered oldest first, so v >= Versions.HTTP_11 works.
  • as_str, string(v) and print give "HTTP/1.1"; HTTP/2 and HTTP/3 print as "HTTP/2.0" and "HTTP/3.0". show prints Versions.HTTP_11.

Examples

julia> Version()
Versions.HTTP_11

julia> Versions.HTTP_10 < Versions.HTTP_11
true

julia> string(Versions.HTTP_2)
"HTTP/2.0"
