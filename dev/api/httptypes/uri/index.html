URIs

This page documents Uri, the type of a request's target, its accessors, and the component types Scheme, Authority, PathAndQuery and Port. Use it to read the path and query of a request, or to parse and build URLs.

Reading a request target

uri(req) returns a Uri. A server normally sees the origin form, a path with an optional query:

julia> using HttpTypes
julia> req = Request(Methods.GET, "/users/42?full=1&sort=name");
julia> u = uri(req)uri"/users/42?full=1&sort=name"
julia> path(u)"/users/42"
julia> query(u)"full=1&sort=name"

There is no host in such a target, so the authority accessors return nothing. The host the client asked for is in the host header:

julia> host(u), port(u), scheme(u)(nothing, nothing, nothing)

query returns nothing when the target has no ?, and an empty string when it ends with one:

julia> query(uri"/users"), query(uri"/users?")(nothing, "")
Nothing is decoded

path and query return the text exactly as the client sent it. %20 stays %20, + stays +, the query is not split into parameters, and .. segments are not resolved. Decode before you compare a path with a file name or use a query value.

julia> path(uri"/files/my%20report.pdf")"/files/my%20report.pdf"

Parsing and building URLs

Uri also parses absolute URLs:

julia> u = Uri("https://user@example.com:8443/a/b?x=1")uri"https://user@example.com:8443/a/b?x=1"
julia> scheme(u), scheme_str(u)(Schemes.HTTPS, "https")
julia> authority(u)Authority("user@example.com:8443")
julia> host(u), port(u), port_u16(u)("example.com", Port(8443), 0x20fb)
julia> path_and_query(u)PathAndQuery("/a/b?x=1")

No default port is filled in:

julia> port(uri"https://example.com/") === nothingtrue

Build a URI from components with keywords, or take one apart with UriParts, change a component and put it back together:

julia> Uri(; scheme = "https", authority = "example.com", path_and_query = "/search?q=julia")uri"https://example.com/search?q=julia"
julia> p = UriParts(uri"http://example.com/a");
julia> p.scheme = Schemes.HTTPS;
julia> Uri(p)uri"https://example.com/a"

Comparison ignores the case of the scheme and host, but not of the path:

julia> uri"HTTP://EXAMPLE.com/a" == uri"http://example.com/a"true
julia> uri"http://example.com/a" == uri"http://example.com/A"false

HttpTypes.Uri — Type
Uri(src)
Uri(ptr::Ptr{UInt8}, len::Integer)
Uri(; scheme = nothing, authority = nothing, path_and_query = nothing)
Uri(parts::UriParts)
Uri(a::Authority)
Uri(pq::PathAndQuery)
tryparse(Uri, src)
parse(Uri, src)

A URI as used in HTTP: the request target of a Request.

Four forms parse:

FormExampleUsed for
origin/users/42?full=1ordinary requests to a server
absolutehttps://example.com/users/42requests to a proxy, client-side URLs
authorityexample.com:443CONNECT
asterisk*OPTIONS *

Arguments

  • src: an AbstractString or AbstractVector{UInt8}, at most 65,534 bytes; or a Uri (returned as is).
  • scheme, authority, path_and_query: components for the keyword form, each a string or an already-parsed Scheme, Authority or PathAndQuery. With no keywords the result is uri"/".
  • parts: a UriParts.

Returns

An immutable Uri. tryparse returns nothing instead of throwing. Read it with scheme, authority, host, port, path, query and path_and_query.

Throws

  • InvalidUri if src or a keyword component does not parse.
  • InvalidUriParts if the components do not combine: a scheme needs an authority and a path; an authority with a path needs a scheme.

Notes

  • Nothing is percent-decoded or normalised, and a fragment (#...) is dropped.
  • A relative reference without a leading slash ("a/b") does not parse as a path; it is read as an authority or rejected.
  • A port that is not a number in 0:65535 does not make the URI invalid; port is then nothing.
  • == and hash work component by component: scheme and authority ignoring ASCII case, path and query exactly. u == "..." compares with a string the same way, ignoring any fragment in the string.
  • string(u) and print give the text; show prints the literal uri"...".
  • For a literal, uri"..." validates when the code is parsed.

Examples

julia> u = Uri("https://example.com:8443/users/42?full=1")
uri"https://example.com:8443/users/42?full=1"

julia> scheme(u), host(u), port(u), path(u), query(u)
(Schemes.HTTPS, "example.com", Port(8443), "/users/42", "full=1")

julia> t = Uri("/users/42?full=1");

julia> host(t) === nothing, path(t)
(true, "/users/42")

julia> Uri(; scheme = "https", authority = "example.com", path_and_query = "/x")
uri"https://example.com/x"

julia> tryparse(Uri, "/has space") === nothing
true

HttpTypes.UriParts — Type
UriParts(; scheme = nothing, authority = nothing, path_and_query = nothing)
UriParts(u::Uri)

The components of a Uri as a mutable struct (the crate's uri::Parts): take a URI apart, change a component, and build a new URI with Uri(parts).

Fields

  • scheme::Union{Nothing,Scheme}
  • authority::Union{Nothing,Authority}
  • path_and_query::Union{Nothing,PathAndQuery}

The keyword constructor and field assignment take already-parsed components (Scheme("https"), Schemes.HTTPS, Authority("example.com"), PathAndQuery("/x")), not strings. Use Uri(; scheme = "https", ...) to build from strings.

Uri(parts) throws InvalidUriParts if the components do not combine.

Examples

julia> p = UriParts(uri"http://example.com/a?x=1");

julia> p.scheme = Schemes.HTTPS;

julia> p.path_and_query = PathAndQuery("/b");

julia> Uri(p)
uri"https://example.com/b"

HttpTypes.path — Function
path(pq::PathAndQuery) -> SubString{String}
path(u::Uri) -> SubString{String}

The path, without the query.

Returns

The path as written: not percent-decoded and not normalised. An empty path reads as "/", except for an authority-form Uri (example.com:443), whose path is "". The asterisk-form target has path "*".

julia> path(uri"/users/42?full=1")

julia> path(uri"https://example.com")

julia> path(uri"/a%20b")
"/a%20b"

julia> path(Uri("example.com:443"))
""

HttpTypes.host — Function
host(a::Authority) -> SubString{String}
host(u::Uri) -> Union{SubString{String},Nothing}

The host: what follows any userinfo@ and precedes any :port.

Returns

The host as written (case is kept). An IPv6 host keeps its brackets. For a Uri without an authority, such as the request target /path, nothing.

Note

A server usually receives origin-form targets (/path?query), whose Uri has no host. The host the client asked for is then in the host header: headers(req)[header.HOST].

Examples

julia> host(uri"https://user@example.com:8443/a")
"example.com"

julia> host(Authority("[::1]:8080"))
"[::1]"

julia> host(uri"/a") === nothing
true

port(a::Authority) -> Union{Port,Nothing}
port(u::Uri) -> Union{Port,Nothing}

The Port written after the host.

HttpTypes.uri_from_target(path_ptr, path_len, query_ptr, query_len) -> Uri

HttpTypes.Scheme — Type
Scheme(src)
Scheme(ptr::Ptr{UInt8}, len::Integer)
tryparse(Scheme, src)
parse(Scheme, src)

The scheme component of a URI, such as http or https.

Schemes.HTTP and Schemes.HTTPS are constants, and parsing "http" or "https" in any case returns them. Any other scheme keeps its text.

Arguments

  • src: an AbstractString or AbstractVector{UInt8} holding the scheme alone (no ://).
  • ptr, len: a pointer to len bytes holding the scheme.

Returns

A Scheme; tryparse returns nothing instead of throwing.

Throws

  • InvalidUri with kind :InvalidScheme for a character other than a letter, digit, +, -, . or ~, or :SchemeTooLong over 64 bytes.

Notes

  • Comparison (with another Scheme or a string) and hashing ignore ASCII case.
  • as_str, string and print give the text as written; show prints Schemes.HTTPS or Scheme("ftp").
  • An empty string is accepted and gives an empty scheme, as in the crate.

Examples

julia> Scheme("https")
Schemes.HTTPS

julia> Scheme("HTTP") === Schemes.HTTP
true

julia> s = Scheme("ftp")
Scheme("ftp")

julia> s == "FTP", string(s)
(true, "ftp")

HttpTypes.Authority — Type
Authority(src)
Authority(ptr::Ptr{UInt8}, len::Integer)
tryparse(Authority, src)
parse(Authority, src)

The authority component of a URI: [userinfo@]host[:port].

Arguments

  • src: an AbstractString or AbstractVector{UInt8} holding the authority and nothing else (no scheme, path, query or fragment).
  • ptr, len: a pointer to len bytes holding the authority.

Returns

An Authority; tryparse returns nothing instead of throwing. host, port and port_u16 read its parts.

Throws

  • InvalidUri: :Empty for empty input, :InvalidUriChar for a forbidden character (including /, ? and #), :InvalidAuthority for a malformed one.

Notes

  • Comparison, ordering and hashing ignore ASCII case, since hosts are case-insensitive. The text itself is kept as written.
  • The port is not validated when the authority is parsed: "example.com:99999" is a valid authority whose port is nothing.
  • as_str, string and print give the text; show prints Authority("example.com:8080").

Examples

julia> a = Authority("user@Example.com:8080")
Authority("user@Example.com:8080")

julia> host(a), port(a), port_u16(a)
("Example.com", Port(8080), 0x1f90)

julia> a == "user@example.com:8080"
true

julia> tryparse(Authority, "example.com/path") === nothing
true
source
HttpTypes.PathAndQuery — Type
PathAndQuery(src)
PathAndQuery(ptr::Ptr{UInt8}, len::Integer)
tryparse(PathAndQuery, src)
parse(PathAndQuery, src)

The path and query of a URI: /a/b?x=1.

Arguments

  • src: an AbstractString or AbstractVector{UInt8} that starts with /, or is *.
  • ptr, len: a pointer to len bytes holding the same.

Returns

A PathAndQuery; tryparse returns nothing instead of throwing. path and query read its two halves.

Throws

  • InvalidUri: :Empty, :PathDoesNotStartWithSlash, :InvalidUriChar (space, control bytes, invalid UTF-8) or :TooLong.

Notes

  • A fragment (#...) is dropped when parsing.
  • Nothing is percent-decoded or normalised: %20, .. and // stay as written, and comparison is byte for byte.
  • as_str, string and print give the text; show prints PathAndQuery("/a?x=1").

Examples

julia> pq = PathAndQuery("/search?q=julia#top")
PathAndQuery("/search?q=julia")

julia> path(pq), query(pq)
("/search", "q=julia")

julia> PathAndQuery("search")
ERROR: path does not start with slash
[...]

HttpTypes.Port — Type
Port(n::Integer)
Port(src)
Port(ptr::Ptr{UInt8}, len::Integer)
tryparse(Port, src)
parse(Port, src)

The port of an authority: a number in 0:65535 together with the text it was written as.

Arguments

  • n::Integer: the port number.
  • src: an AbstractString or AbstractVector{UInt8} holding decimal digits, optionally after a +; or a Port (returned as is).

Returns

A Port; tryparse (which also accepts an integer) returns nothing instead of throwing.

Throws

  • InvalidUri with kind :InvalidPort for a number outside 0:65535 or text that is not such a number.

Notes

  • UInt16(p) is the number. p == 8080 compares with an integer; two ports are equal when their numbers are, however they were written.
  • as_str gives the text as written ("+80", "080"); string and print give the number ("80"); show prints Port(80).

Examples

julia> p = Port(8080)
Port(8080)

julia> p == 8080, Int(UInt16(p)), string(p)
(true, 8080, "8080")

julia> q = Port("+80");

julia> as_str(q), string(q)
("+80", "80")

julia> tryparse(Port, 70_000) === nothing
true
