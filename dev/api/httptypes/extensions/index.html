Extensions

This page documents Extensions, the typed side-channel that every Request and Response carries. Use it to attach data to a message that is not part of HTTP, such as a request id or the authenticated user, and read it back later by type.

Using extensions

An Extensions holds at most one value per type. The type is the key, so define a small struct for each kind of data:

julia> using HttpTypes
julia> struct RequestId
           value::Int
       end
julia> struct User
           name::String
       end
julia> req = Request(Methods.GET, "/account");
julia> insert!(extensions(req), RequestId(7));
julia> insert!(extensions(req), User("ada"));
julia> get(extensions(req), User)Main.User("ada")
julia> get(extensions(req), RequestId).value7

get returns nothing (or a default you pass) when no value of that type is stored; indexing throws instead:

julia> struct Session end
julia> get(extensions(req), Session)
julia> get(extensions(req), Session, "fallback")"fallback"
julia> haskey(extensions(req), Session)false

get! stores a value on first use, which suits per-request scratch data:

julia> push!(get!(extensions(req), Vector{String}), "checked auth");
julia> push!(get!(extensions(req), Vector{String}), "loaded user");
julia> extensions(req)[Vector{String}]2-element Vector{String}:
 "checked auth"
 "loaded user"

Extensions can also be given at construction, as a tuple of values:

julia> r = Request(; uri = "/x", extensions = (RequestId(1), User("bob")));
julia> length(extensions(r))2
Note

The key is the exact type of the value. A value stored as Int32 is not found by get(ext, Integer) or get(ext, Int).

Reference

HttpTypes.Extensions — Type
Extensions()

A type map: a collection that holds at most one value per type, keyed by the value's own type.

Every Request and Response has one (extensions(r)). It carries data that belongs to a message but is not part of HTTP: a request id, an authenticated user, a start time. Give each kind of data its own struct type so that unrelated code cannot collide.

Notes

  • The key is the exact concrete type: a value stored as Int32 is not found by get(ext, Integer).
  • The values of get! are converted to T.
  • The map allocates nothing until the first insert, so an unused Extensions is free.
  • show lists the stored types only, never the values.
  • Not thread-safe; do not change one map from two tasks at once.

Examples

julia> struct RequestId
           value::Int
       end

julia> ext = Extensions();

julia> insert!(ext, RequestId(7)) === nothing
true

julia> get(ext, RequestId)
RequestId(7)

julia> insert!(ext, RequestId(8))
RequestId(7)

julia> get(ext, String) === nothing, get(ext, String, "none")
(true, "none")

julia> haskey(ext, RequestId), length(ext)
(true, 1)

julia> remove!(ext, RequestId), isempty(ext)
(RequestId(8), true)

Base.insert! — Method
insert!(ext::Extensions, val)

Store val, keyed by typeof(val), replacing any value of that type.

Returns

The value that was replaced, or nothing if there was none.

Examples

julia> ext = Extensions();

julia> insert!(ext, 1) === nothing
true

julia> insert!(ext, 2)
1

julia> ext[Int]
2

Base.get — Method
get(ext::Extensions, T::Type)
get(ext::Extensions, T::Type, default)

The stored value of type T, or default (nothing when not given) if there is none. ext[T] throws a KeyError instead, and haskey(ext, T) tests for presence.

julia> get(ext, String)

julia> get(ext, Int) === nothing, get(ext, Int, 0)
