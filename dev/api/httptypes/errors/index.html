Errors

This page lists every error HttpTypes throws and what causes each. Use it to decide what to catch around code that builds HTTP values from untrusted text.

Handling errors

All of them are subtypes of HttpError, so one catch covers every validation failure:

julia> using HttpTypes
julia> function parse_target(text)
           try
               Uri(text)
           catch e
               e isa HttpError || rethrow()
               "rejected: " * sprint(showerror, e)
           end
       endparse_target (generic function with 1 method)
julia> parse_target("/users/42")uri"/users/42"
julia> parse_target("/users/4 2")"rejected: invalid uri character"

When a failure is expected, tryparse avoids the exception altogether:

julia> tryparse(StatusCode, "20x") === nothingtrue
julia> tryparse(HeaderValue, "line\nbreak") === nothingtrue
ErrorMessageThrown by
InvalidMethodinvalid HTTP methodHttpMethod, Request(; method)
InvalidStatusCodeinvalid status codeStatusCode, Response(; status)
InvalidHeaderNameinvalid HTTP header nameHeaderName, HeaderMap writes, entry
InvalidHeaderValuefailed to parse header valueHeaderValue, HeaderMap writes
ToStrErrorfailed to convert header to a strto_str
MaxSizeReachedmax size reachedHeaderMap growth, reserve!
InvalidUridepends on kindUri, Scheme, Authority, PathAndQuery, Port
InvalidUriPartsdepends on the causeUri(parts), Uri(; scheme, authority, path_and_query)

Lookups that miss are not HttpErrors: headers[name] and extensions[T] throw KeyError, like a Dict.

Reference

HttpTypes.HttpError — Type
HttpError <: Exception

Supertype of every error this package throws.

ErrorThrown when
InvalidMethoda method is not a valid token
InvalidStatusCodea status code is outside 100:999
InvalidHeaderNamea header name is not a valid token
InvalidHeaderValuea header value holds a forbidden byte
ToStrErrorto_str meets a byte outside visible ASCII
MaxSizeReacheda HeaderMap would exceed its size limit
InvalidUria URI or one of its components does not parse
InvalidUriPartsUriParts do not combine into a URI

HttpTypes.Error wraps any of them in one concrete type.

Catch HttpError to handle every validation failure in one place. Lookups that miss throw the usual Base errors instead (KeyError), and passing a value of the wrong type is a MethodError or ArgumentError.

Examples

julia> try
           Request(; method = "G T")
       catch e
           e isa HttpError, sprint(showerror, e)
       end
(true, "invalid HTTP method")
source
HttpTypes.InvalidMethod — Type
InvalidMethod <: HttpError

Thrown by HttpMethod (and by anything that converts to one, such as Request(; method = ...)) when the source is empty or holds a byte that is not an RFC 9110 token character. The message is invalid HTTP method.

Examples

julia> HttpMethod("G T")
ERROR: invalid HTTP method
[...]

julia> tryparse(HttpMethod, "G T") === nothing
true
source
HttpTypes.InvalidStatusCode — Type
InvalidStatusCode <: HttpError

Thrown by StatusCode (and by anything that converts to one, such as Response(; status = ...)) for an integer outside 100:999, or for text that is not exactly three ASCII digits with a non-zero first digit. The message is invalid status code.

Examples

julia> StatusCode(99)
ERROR: invalid status code
[...]

julia> tryparse(StatusCode, 1000) === nothing
true
source
HttpTypes.InvalidHeaderName — Type
InvalidHeaderName <: HttpError

Thrown by HeaderName, and by every HeaderMap function that has to build a name from a string, when the source is not a valid header field name: an RFC 9110 token of 1 to 65,535 bytes. The message is invalid HTTP header name.

Examples

julia> HeaderName("bad name")
ERROR: invalid HTTP header name
[...]

julia> tryparse(HeaderName, "") === nothing
true
source
HttpTypes.InvalidHeaderValue — Type
InvalidHeaderValue <: HttpError

Thrown by HeaderValue, and by every HeaderMap function that converts a value, when the source holds a forbidden byte: a control byte other than tab, DEL, or (for a string source) any non-ASCII byte. Line breaks are control bytes, so a value can never span lines. The message is failed to parse header value.

Examples

julia> HeaderValue("café")
ERROR: failed to parse header value
[...]
source
HttpTypes.ToStrError — Type
ToStrError <: HttpError

Thrown by to_str when a HeaderValue holds a byte outside visible ASCII (and tab). The message is failed to convert header to a str.

Examples

julia> to_str(HeaderValue(UInt8[0xff]))
ERROR: failed to convert header to a str
[...]
source
HttpTypes.MaxSizeReached — Type
MaxSizeReached <: HttpError

Thrown when a HeaderMap would grow past its limit: more than 24,576 distinct names, or a capacity above that asked of HeaderMap{T}(capacity), sizehint! or reserve!. The message is max size reached.

Examples

julia> HeaderMap{HeaderValue}(40_000)
ERROR: max size reached
[...]

HttpTypes.InvalidUri — Type
InvalidUri <: HttpError

Thrown when text does not parse as a Uri or as one of its components (Scheme, Authority, PathAndQuery, Port).

Fields

  • kind::Symbol: what was wrong.
kindMessageTypical cause
:InvalidUriCharinvalid uri charactera space, control byte or other forbidden character
:InvalidSchemeinvalid schemea scheme with a forbidden character
:InvalidAuthorityinvalid authorityunbalanced [ ], nothing after @
:InvalidPortinvalid porta port that is not a number in 0:65535
:InvalidFormatinvalid formatcomponents in an impossible arrangement

:AuthorityMissingauthority missinga scheme without an authority (parts)

HttpTypes.InvalidUriParts — Type
InvalidUriParts <: HttpError

Thrown by Uri(parts::UriParts) and by the keyword form Uri(; scheme, authority, path_and_query) when the components given do not make a URI: a scheme needs both an authority and a path, and an authority with a path needs a scheme.

Fields

  • err::InvalidUri: the cause; its kind is :SchemeMissing, :AuthorityMissing or :PathAndQueryMissing.

Examples

julia> Uri(; scheme = "https")
ERROR: authority missing
[...]

julia> try
           Uri(; authority = "example.com", path_and_query = "/x")
       catch e
           e isa InvalidUriParts, e.err.kind
       end
(true, :SchemeMissing)

HttpTypes.Error — Type
HttpTypes.Error(err::HttpError)

One concrete error type that wraps any HttpError (the crate's general http::Error). Not exported.

Nothing in this package throws an Error; it exists for code that wants to store or return a single error type.

Arguments

  • err::HttpError: the error to wrap. An Error is returned unchanged, so errors never nest.

Returns

An Error. HttpTypes.get_ref gives back the wrapped error. showerror prints the wrapped error's message. convert(HttpTypes.Error, err) does the same as the constructor.

Examples

julia> err = HttpTypes.Error(InvalidMethod())
HttpTypes.Error(InvalidMethod())

julia> HttpTypes.get_ref(err) isa InvalidMethod
true

julia> HttpTypes.Error(err) === err
true

julia> sprint(showerror, err)
"invalid HTTP method"
source

HttpTypes.get_ref(e::HttpTypes.Error) -> HttpError

The specific error wrapped by an HttpTypes.Error. Not exported.
