Configuration

This page lists every setting of a Facil server in one place: the keywords of serve and serve!, the process-wide settings, the options of the response functions, and the Julia flags and environment variables that matter. Each entry links to the guide that explains it.

serve and serve! keywords

serve(handler, host = "127.0.0.1", port = 8080; keywords...). Both functions take the same keywords. Here they all are at their defaults; the documentation build checks this program against the defaults in the code:

using Facil

# Every keyword of `serve` and `serve!`, written out at its default value.
serve(req -> Response(StatusCodes.OK, "ok"), "127.0.0.1", 8080;
      inline = false,
      reactors = 1,
      max_header_size = 32 * 1024,
      max_body_size = 50 * 1024 * 1024,
      body_in_memory = 16 * 1024 * 1024,
      timeout = 40,
      header_timeout = 30,
      max_pending_output = 16 * 1024 * 1024,
      before_body = head -> Buffer(),
      compress = false,
      public_folder = nothing,
      tls = nothing,
      shutdown_grace = 10,
      verbose = false,
      gc_headroom = 0)

Handlers and threads

KeywordTypeDefaultEffect
inlineBoolfalsefalse: handlers run on worker tasks and may block. true: handlers run on the reactor thread and must not block. Forced to true when Julia has one thread. Guide
reactorsInteger ≥ 11Number of reactor (event-loop) threads. Process-wide, fixed by the first server; a different value later throws. Must be 1 with tls. Guide

Limits and timeouts

KeywordTypeDefaultEffect
max_header_sizeInteger ≥ 102432768 (32 KiB)Largest request head in bytes. Larger: 431, connection closed.
max_body_sizeInteger ≥ 052428800 (50 MiB)Largest request body in bytes, however it is received. Larger: 413, connection closed.
body_in_memoryInteger ≥ 016777216 (16 MiB)Largest body Buffer() holds in memory. Larger: 413. Does not apply to Stream() and Spool().
timeoutInteger, 1 to 25540Seconds an idle connection is kept open.
header_timeoutInteger, 0 to 360030Seconds a client has to send a complete request head; a client still sending after that gets 408. 0 disables. Process-wide: the last server started sets it.
max_pending_outputInteger ≥ 016777216 (16 MiB)A client with more unsent response bytes than this that stops reading for about 3 seconds is disconnected. 0 disables.

See Limits and Security.

Request bodies

KeywordTypeDefaultEffect
before_bodyfunction RequestHead -> Buffer, Stream, Spool or Rejecthead -> Buffer()Called on the reactor thread for each request that has a body, before the body is read; chooses where the body goes. Guide

Responses

KeywordTypeDefaultEffect
compressBool or CompressOptionsfalseCompress responses with zstd, brotli or gzip according to Accept-Encoding. true is CompressOptions(). Guide
public_folderNothing or AbstractStringnothingA directory served for GET, HEAD and OPTIONS before the handler is called; requests that match no file reach the handler. Guide
dotfiles:serve or :deny:serve:deny: public_folder does not serve a path with a part that starts with a dot (.env, .git/config); the request reaches the handler. Guide
symlinks:follow or :inside:follow:inside: public_folder does not serve a file that resolves to a place outside the folder; the request reaches the handler. Guide

HTTPS

KeywordTypeDefaultEffect
tlsNothing or TLSConfignothingServe HTTPS with these certificates and settings. Needs reactors = 1. Guide

Operation

KeywordTypeDefaultEffect
shutdown_graceReal ≥ 010Seconds that requests in flight get to finish when a process running serve receives SIGTERM (or Ctrl-C in a script). Guide
verboseBoolfalseWrite a start-up line (address, threads, limits) and a line per request rejected by before_body or body_in_memory to stderr. Guide
gc_headroomInteger ≥ 00Bytes of heap headroom; calls Facil.gc_headroom!. Process-wide, only grows. Guide

An out-of-range value throws ArgumentError when the server starts. So does an unknown keyword; the message names the closest valid keyword and lists all of them.

Positional arguments

ArgumentTypeDefaultNotes
handlerany callablerequiredhandler(req::Request{String}); first argument, so do blocks work
hostAbstractString"127.0.0.1""0.0.0.0" for all IPv4 interfaces, "::" for IPv6; host names are resolved
portInteger, 0 to 6553580800 picks a free port; read it with port(server)

serve(handler, port) is short for serve(handler, "127.0.0.1", port).

Julia flags and environment variables

SettingEffect
julia -t N or JULIA_NUM_THREADS=NJulia threads for task handlers. With 1, handlers run inline.
julia --gcthreads=N or JULIA_NUM_GC_THREADS=NGarbage-collector threads; shortens pauses on -t 1 servers.
julia -J image.soStart from a system image; see Deployment.
FACIL_VERBOSE=1Raise facil.io's own log level from warnings to informational messages. Read when Facil is loaded. For diagnosing the C library.
FACIL_JL_LOCAL_BUILD=1Prefer a locally built C library over a prebuilt one. Read when Facil is precompiled.
libfacil_path preferencePath of the C library to load, set with Preferences.jl. For developing the C code.
