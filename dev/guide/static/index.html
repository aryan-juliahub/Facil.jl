Static files

This page shows the two ways to send files: public_folder, which serves a directory without calling your handler, and sendfile, which sends one file from a handler. Both use facil.io's file sender, so both get caching headers, conditional requests, ranges and sendfile(2).

A site with public and private files

using Facil

const ROOT = get(ENV, "SITE_ROOT", @__DIR__)
const PUBLIC = joinpath(ROOT, "public")      # served as is: /app.css -> public/app.css
const REPORTS = joinpath(ROOT, "reports")    # private: sent only by the handler

Facil.register_mime!("geojson", "application/geo+json")

function app(req)
    p = path(uri(req))
    if startswith(p, "/reports/")
        name = chopprefix(p, "/reports/")
        # Never build a file path from request text without checking it.
        occursin(r"^[A-Za-z0-9_-]+\.csv$", name) || return Response(StatusCodes.BAD_REQUEST, "bad report name\n")
        sendfile(joinpath(REPORTS, name); headers = [header.CONTENT_DISPOSITION => "attachment"])
    else
        Response(StatusCodes.NOT_FOUND, "no such page\n")
    end
end

serve(app, "127.0.0.1", 8080; public_folder = PUBLIC)

With this layout next to the script:

public/index.html
public/app.css
public/app.css.gz
public/docs/index.html
reports/q3.csv
$ curl http://127.0.0.1:8080/docs/
docs index
$ curl http://127.0.0.1:8080/reports/q3.csv
quarter,revenue
q3,100
$ curl http://127.0.0.1:8080/missing.html
no such page

Serving a directory with public_folder

public_folder = dir is a keyword of serve!. Before the handler is called, Facil looks for the request's path under dir:

  • A GET, HEAD or OPTIONS request for a file that exists is answered from the folder. The handler is not called, and before_body, compress and your own headers do not apply.
  • A path ending in / serves index.html from that directory (/ serves dir/index.html).
  • Everything else reaches the handler: other methods, paths with no file, directories without index.html, and a directory named without its trailing slash (/docs is not redirected to /docs/).

The path is percent-decoded before the lookup (/release%20notes.txt finds release notes.txt) and the query string is ignored. Files are looked up at request time: files you add or change while the server runs are served without a restart.

dir is resolved to an absolute path when the server starts, relative to the directory Julia was started in; a directory that does not exist throws an ArgumentError there.

Everything in the folder is public

By default dotfiles are served (public/.env answers /.env) and symbolic links are followed, also out of the folder. Put only files meant for the world in the folder, and do not point it at a project root or a directory that holds uploads you have not vetted.

What is never served, and what you can turn off

Request pathResult
contains .. as a path part, or // (also when percent-encoded)never served from the folder; reaches your handler, with the path as sent
contains an encoded NUL (%00)400 Bad Request; the handler is not called
has a part that starts with a dot (/.env, /.git/config)served by default; with dotfiles = :deny it reaches your handler as if the file did not exist
names a symbolic link, or goes through onefollowed by default; with symlinks = :inside a file that resolves to a place outside the folder reaches your handler instead
serve!(app, 8080; public_folder = "public", dotfiles = :deny, symlinks = :inside)

The defaults are those of nginx, which serves dotfiles and follows links (Node's serve-static follows links too, but ignores dotfiles). A folder you fully control needs neither option. Turn both on when other people or tools can put files into the folder. With symlinks = :inside, links that stay inside the folder still work, and the folder itself may be reached through a link.

Sending one file with sendfile

sendfile(path) returns a response that sends the file at path. Use it for files outside the public folder, downloads behind a login, and files whose name you compute.

CaseAnswer
the file exists, method GET or HEADthe file (or its head), with status (default 200)
method OPTIONS200 with allow: GET, HEAD
any other method405 with allow: GET, HEAD, OPTIONS
path is missing or is a directory404

Headers you pass with headers are sent too, except the ones the file sender sets itself (content-type, etag, cache-control, last-modified, content-length, accept-ranges, content-range, content-encoding).

`sendfile` trusts its path

The path is used as given: it is not percent-decoded and not confined to any folder. sendfile(joinpath(dir, user_input)) lets a request for ../../etc/passwd out of dir. Check request text against a strict pattern first, as the example does, or look the name up in a list of files you know.

sendfile(req, path) is the same; the request is accepted for symmetry with stream and not used.

What the file sender does

For public_folder and sendfile alike:

FeatureBehaviour
content-typefrom the file extension; application/octet-stream when unknown
etagderived from the file's size and modification time
last-modifiedthe file's modification time
cache-controlalways max-age=3600
If-None-Match304 when the ETag matches
If-Modified-Sinceignored: the file is sent
Rangeone range (bytes=0-99, bytes=100-, bytes=-50) gives 206 with content-range; an unsatisfiable one gives 416; several ranges give the whole file with 200
If-Rangehonoured with an ETag
HEADheaders only
gzipwhen the client's Accept-Encoding has gzip and file.gz exists next to file, the .gz file is sent with content-encoding: gzip

Things to know:

  • Caching cannot be changed. Every file is sent with cache-control: max-age=3600, and a cache-control you pass to sendfile is replaced. Browsers may reuse a file for an hour without asking. Put a version or content hash in file names you change in place (app.3f9a.css), or serve such files from a handler as an ordinary Response.
  • The ETag is not a content hash. A file rewritten within the same second with the same size keeps its ETag.
  • Files are not compressed on the fly, whatever compress says. Create the .gz sibling when you build your assets (gzip -k -9 app.css). Only gzip siblings are looked for, not .br or .zst.

Content types

The type comes from the extension, case-insensitively, from facil.io's table plus Facil's additions for current web formats (.js and .mjs as text/javascript, .wasm, .webp, .avif, .woff2, .webmanifest, .svg, .json, .md, and so on; text types carry charset=utf-8).

Facil.mime_type(path) tells you what a name maps to, and Facil.register_mime!(ext, type) adds or replaces an entry:

using Facil

Facil.mime_type("index.html"), Facil.mime_type("photo.JPG"), Facil.mime_type("data.parquet")
("text/html; charset=utf-8", "image/jpeg", "application/octet-stream")
Facil.register_mime!("parquet", "application/vnd.apache.parquet")
Facil.mime_type("data.parquet")
"application/vnd.apache.parquet"

The table is process-wide and has no lock: register your types before the first server starts. An extension is 1 to 15 bytes, without the dot (a leading dot is dropped).
