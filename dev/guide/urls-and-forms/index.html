Query strings, paths and forms

This page shows how to decode what is percent-encoded in a request: the query string, the path, and application/x-www-form-urlencoded bodies (what an HTML <form method="post"> sends). The helpers follow the same rules as the WHATWG URL standard behind Node's URLSearchParams and Rust's form_urlencoded.

You wantCallResult
one query parameterquery_param(req, "name"; default = nothing)the first value, decoded, or default
every query parameterquery_params(req)Vector{Pair{String,String}}, in order, repeats kept
the decoded pathdecoded_path(req)String, or nothing if it cannot be decoded safely
a form bodyparse_form(req)Vector{Pair{String,String}}, like query_params
any query-like stringparse_query(s)the same pairs, from a String
decode or encode one piecepercent_decode(s), percent_encode(s)String

The raw values are still there: path(uri(req)) and query(uri(req)) are what the client sent (see Reading requests).

Query parameters

using Facil

serve("127.0.0.1", 8080) do req
    p = decoded_path(req)
    p === nothing && return Response(StatusCodes.BAD_REQUEST, "bad path\n")
    name = query_param(req, "name"; default = "world")
    tags = [v for (k, v) in query_params(req) if k == "tag"]
    Response(StatusCodes.OK, "path: $p\nhello $name\ntags: $(join(tags, ", "))\n")
end
$ curl 'http://127.0.0.1:8080/caf%C3%A9/menu?name=Ada+L&tag=a&tag=b%26c'
path: /café/menu
hello Ada L
tags: a, b&c

query_params splits the query on &, splits each piece at its first =, turns + into a space and percent-decodes both sides. A piece without = has the value "", empty pieces are skipped, and a name that appears twice gives two pairs:

using Facil

req = Request(; uri = "/search?q=julia+web&tag=a&tag=b&flag&empty=")
query_params(req)
5-element Vector{Pair{String, String}}:
     "q" => "julia web"
   "tag" => "a"
   "tag" => "b"
  "flag" => ""
 "empty" => ""

The result is a vector so that nothing is lost. Turn it into what you need:

q = query_params(req)
Dict(q)                                  # last value of each name wins
Dict{String, String} with 4 entries:
  "flag"  => ""
  "empty" => ""
  "q"     => "julia web"
  "tag"   => "b"
[v for (k, v) in q if k == "tag"]       # every value of one name
2-element Vector{String}:
 "a"
 "b"

query_param(req, name) is the first value of name (the same as URLSearchParams.get). It decodes only the names until it finds a match, so it is the cheaper call when you need one or two parameters. Convert numbers yourself and decide what a bad value means:

page = something(tryparse(Int, query_param(req, "page"; default = "1")), 1)
1

Paths

decoded_path(req) percent-decodes the path: /caf%C3%A9 becomes /café. + stays +, because only queries and forms use it for a space.

It returns nothing when decoding the whole path would be ambiguous or unsafe, so you can answer 400:

Path containsWhy it is refused
%2F (an encoded /)after decoding, it could not be told apart from a separator
%00a NUL byte truncates C strings and file names
a malformed escape (%zz, %4, a final %)it has no meaning
bytes that are not valid UTF-8 (%FF)the result would not be a valid String
decoded_path(Request(; uri = "/caf%C3%A9/a+b")), decoded_path(Request(; uri = "/files/a%2Fb"))
("/café/a+b", nothing)

The decoded path is not normalised: /a/%2E%2E/b decodes to /a/../b. Never join it to a directory without checking; sendfile and public_folder do their own checks.

If your URLs may carry an encoded / inside one segment (a file name, an identifier), split the raw path first and decode each segment:

segments = percent_decode.(split(path(uri(Request(; uri = "/files/a%2Fb/v1"))), '/'; keepempty = false))
3-element Vector{String}:
 "files"
 "a/b"
 "v1"

Forms

A browser posting an HTML form, and curl -d or --data-urlencode, send an application/x-www-form-urlencoded body. parse_form(req) parses body(req) with the query rules above. Check the content-type first if the route also accepts other bodies:

using Facil

const FORM = "application/x-www-form-urlencoded"

serve("127.0.0.1", 8080) do req
    method(req) == Methods.POST ||
        return Response(StatusCodes.METHOD_NOT_ALLOWED; headers = [header.ALLOW => "POST"])
    ct = get(headers(req), header.CONTENT_TYPE, nothing)
    ct !== nothing && startswith(as_str(ct), FORM) ||
        return Response(StatusCodes.UNSUPPORTED_MEDIA_TYPE, "send $FORM\n")
    form = parse_form(req)
    user = something(get(Dict(form), "user", nothing), "")
    isempty(user) && return Response(StatusCodes.BAD_REQUEST, "user is required\n")
    roles = [v for (k, v) in form if k == "role"]
    Response(StatusCodes.OK, "welcome $user\nroles: $(join(roles, ", "))\n")
end
$ curl http://127.0.0.1:8080/signup -d 'user=Ada+Lovelace&role=admin&role=dev%26ops'
welcome Ada Lovelace
roles: admin, dev&ops

parse_form also takes a String or bytes, for example a body you read with body_stream. multipart/form-data (file uploads from a form) is a different format and is not parsed by Facil.

Decoding rules

Decoding never throws on what a client sends. Following the WHATWG URL standard, a % that is not followed by two hex digits is kept as it is, and bytes that do not form valid UTF-8 become '�':

percent_decode("100%"), percent_decode("a%zz"), percent_decode("%FF"), percent_decode("a+b"; plus = true)
("100%", "a%zz", "�", "a b")

percent_encode escapes every byte except A-Z a-z 0-9 - . _ ~. Use it to build a query string, a location header or a cookie value:

"/search?q=" * percent_encode("café & co")
"/search?q=caf%C3%A9%20%26%20co"
