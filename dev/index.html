Facil.jl

Facil is an HTTP server for Julia. You write a function that takes a request and returns a response; Facil does the rest: HTTP/1.1, HTTPS, WebSockets, server-sent events, streaming, static files and compression.

using Facil

serve("127.0.0.1", 8080) do req
    Response(StatusCodes.OK, "hello")
end
$ julia -t 4 hello.jl &
$ curl http://127.0.0.1:8080/
hello

Under the hood, the sockets, the event loop and the HTTP parser are facil.io, a C library. The request and response types are HttpTypes, a pure-Julia port of the Rust http crate, which Facil re-exports. Your handlers are plain Julia and run on Julia's threads.

What to know before you choose Facil

  • HTTP/1.1 only. No HTTP/2 or HTTP/3; put a proxy in front if you need them.
  • Linux and macOS. On Windows, use WSL2 (Platform support).
  • Not registered yet. Installing needs a clone and a C compiler for now.
  • A server, not a framework. There is no router, no middleware stack and no HTTP client. Handlers are functions; the guides show how far that goes.
  • Fast, with known exceptions. Facil is at or above Node.js on 76 of the 100 rows of its benchmark scoreboard and within 4% on 5 more; start-up time, memory and garbage-collection pauses are where it is behind.

About these docs

Every example on this site is a program in docs/examples that the documentation build starts on a free port and checks with a client, or a doctest that the build runs. If an example here does not work for you, that is a bug: please report it. The changelog lists what changed.
